What is Orienteering?

Orienteering is a sport were the goal is to navigate to checkpoints in the quickest most efficient way. There are two main types of orienteering: Set Course and Rogaine

Set Course:

Set course is generally what is referred to when someone talks about orienteering. With a set course you are given a map with controls listed in an order, and you have to get to all of them in the correct order, and in the shortest period of time. There are generally four difficulty's of course: White being easiest, then yellow, orange and red at the hardest.

Rogaine:

Rogaine's are different to set courses, because all controls are optional. This makes it easier than a set course as missing a control isn't a big deal. Rather then being given a course, you are given a map with lots of scattered controls (usually 30) and your goal is to get as many as possible in the given time limit (usually 1 hour). If two or more people tie on points, the person with the shortest time wins.
